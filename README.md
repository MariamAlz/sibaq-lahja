# Sibaq Lahja

> **Program:** Sibaq Lahja, Coders HQ · Arabic NLP program by the UAE Artificial Intelligence Office and Cisco

Reference material from Sibaq Lahja, where I worked on Arabic diacritization using sequence-to-sequence models, Hidden Markov Models (Viterbi), Bidirectional LSTMs and ensembles. This repository holds the program's lecture slides, an exercise sheet and a research paper.

## Contents

| File | Description |
|---|---|
| `Introduction to Arabic Natural Language Processing part 1.pdf` | Lecture by Kareem Darwish. Covers what makes Arabic different for NLP, including its morphology, dialects and diacritization. |
| `Arabic Diacritization Talk.pdf` | Talk by Kareem Darwish, "Arabic diacritization: Classical ML, RNNs, and Seq2seq models". Covers the Farasa toolkit, HMM and CRF approaches, SVMRank for case endings, and RNN and seq2seq models. |
| `Sequence-Labeling.pdf` | Lecture by Mohamed Elbadrashiny, "Introduction to Sequence Labeling". Covers Hidden Markov Models and the Viterbi algorithm. |
| `Viterbi-Exercise .pdf` | Exercise by Mohamed Elbadrashiny on writing the Viterbi algorithm for bigram language-model diacritization over a search lattice. |
| `W10-2405.pdf` | Paper: Jiampojamarn et al., "Transliteration Generation and Mining with Limited Training Resources" (ACL Anthology W10-2405). |
